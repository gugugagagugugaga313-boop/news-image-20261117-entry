A program that draws a one-page newspaper front page summing up the world news of Tuesday 17 November 2026: the Kerch bridge struck again, tankers mined near the Strait of Hormuz, a Xi-Trump-Putin summit set for Shenzhen, jets scrambled over Japan, the Pentagon's ninth failed audit, and a Rwanda return hub — plus a footer ticker of three more stories from the same day. It uses only the Python standard library: the PNG is encoded by hand and every picture is drawn from shapes, with text rasterised from a small built-in bitmap font.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
